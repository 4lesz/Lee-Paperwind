## 0. 怎么用这份文档

- 每条标准有唯一编号（如 `AC-F03`），开发、测试、问题记录都用这个编号。
- **级别**：`P0` 不通过就不能发布；`P1` 不通过需要在发布说明里写明原因和计划修复的版本。
- **验证方式**：
  - `自动`：由自测脚本 `scripts/selftest.cjs` 驱动真实应用执行并断言，输出截图和结果；
  - `手动`：按步骤人工操作检查（涉及系统对话框、安装、双击文件等自动化够不到的部分）；
  - `目视`：对照设计规范检查截图。
- **测试样本**：`samples/示例.md`（覆盖所有语法）、`samples/img/`（本地图片）。需要时补充：大文件样本（≥1MB）、带 BOM 的文件、只读文件、文件名含空格和中文的文件。
- 一个版本发布前，必须产出一份**验收记录**（`docs/验收记录-vX.Y.md`）：逐条写结果（通过 / 不通过 / 不适用）和证据（截图、输出）。
