# Paperwind — 设计规范

> 版本：v1.7 ｜ 日期：2026-11-24 ｜ 适用范围：v0.1 及以后所有界面
> 配套文档：[PRD](../PRD.md) · [验收标准](./验收标准.md) · [执行原则](./执行原则.md)
> 变更：v1.1 按苹果设计理念整体修订——圆润、简洁、内容优先（详见文末变更记录）；v1.7 新增查找替换条（§4.15）

本规范是界面实现的**唯一依据**。代码中的颜色、尺寸、圆角、字号等数值必须来自本规范定义的设计变量（Token），不允许在组件里写死临时数值。规范需要改动时，先改本文档，再改代码。

## 1. 设计理念

整体设计遵循苹果《人机界面指南》（Human Interface Guidelines）的核心理念，目标是**用起来像一款苹果自带的应用**——参照对象是 macOS / iPadOS 上的「备忘录」。

### 1.1 三个核心理念

| 理念 | 含义 | 在本产品中的体现 |
|------|------|------------------|
| **清晰** Clarity | 文字易读、图标一看就懂、重点一眼可见 | 正文用大字号和舒适行距；图标线条统一；只在需要强调的地方使用主色 |
| **遵从内容** Deference | 界面是为内容服务的，退到内容后面 | 去掉多余线条和边框；工具栏轻、浅、半透明；正文区域占满视野 |
| **层次** Depth | 用层次而不是线条来区分区域 | 用背景深浅、半透明材质和柔和阴影区分「窗口 → 侧栏 → 正文 → 浮层」 |

### 1.2 两个视觉关键词

**圆润**
- 所有可交互元素和容器都用圆角，不出现直角卡片或直角按钮。
- 圆角按尺寸分级（§3.4），尺寸越大圆角越大。
- **同心圆角**：容器里嵌套的元素，内圆角 = 外圆角 − 内边距，让内外弧线保持平行（苹果称为 concentricity）。
- 小而独立的控件（标签、气泡、浮动菜单）用**胶囊形**（圆角 = 高度的一半）。

**简洁**
- **少线条**：优先用留白和背景色差来分区，分隔线只在确实需要时使用，并且是极淡的细线。
- **少颜色**：只有一个主色（备忘录黄），其余全是中性灰阶。
- **少控件**：只露出常用操作，低频操作放进菜单；每个功能只有一个界面入口（菜单和快捷键除外）。
- **少装饰**：不用渐变、描边阴影、花哨动画。

### 1.3 设计原则（落地规则）

| # | 原则 | 含义 | 反例（不要这样做） |
|---|------|------|------------------|
| P1 | **内容第一** | 正文是界面的主角，界面元素要安静、低对比 | 彩色大按钮、粗边框、满屏分隔线 |
| P2 | **所见即所得，所存即标准** | 屏幕上看到什么，保存的就是对应的标准 Markdown | 用自定义标记保存颜色、字体大小 |
| P3 | **一步可达** | 常用格式一次点击完成；所有按钮都有快捷键 | 加粗要先打开二级菜单 |
| P4 | **状态可见** | 当前格式、是否已保存、当前模式随时可见 | 点了按钮没反馈、保存了没提示 |
| P5 | **不丢数据** | 可能丢失修改的操作都要先确认；异常退出可恢复草稿 | 直接覆盖、静默丢弃 |
| P6 | **圆润一致** | 圆角只从 §3.4 的刻度取值，嵌套遵守同心规则 | 同一层级的按钮有的 4px 有的 12px |
| P7 | **用层次代替线条** | 区域之间靠背景色差和材质区分 | 每个区域都套一圈边框 |

### 1.4 平台说明（Windows）

- 苹果的 SF Pro 字体和 SF Symbols 图标按授权只能用于苹果平台，本产品在 Windows 上用**最接近的等价方案**：系统字体 Segoe UI Variable（同为现代无衬线、可变字重），图标用造型接近 SF Symbols 的圆头线条图标（§3.5）。
- 半透明材质使用 Windows 11 自带的 **Mica（云母）材质**，效果接近 macOS 侧栏的半透明感；系统不支持时退回纯色。
- 窗口的关闭/最小化/最大化按钮保持 Windows 原生样式和位置（右上角），**不模仿 macOS 的红绿灯**——遵守所在平台的习惯，本身就是苹果的理念。

## 2. 布局

### 2.1 整体结构

```
┌───────────────────────────────────────────────────────────────┐
│ ▣  ＋ 打开 保存        示例.md ●      (编辑|阅读) 源码 ◐ │ — □ × │  ← 统一标题栏 52px（Mica 半透明）
├──────────────┬────────────────────────────────────────────────┤
│              │      ╭──────── 格式栏（胶囊，悬浮，吸顶）────────╮      │
│  大纲         │      │ Aa▾ │ B I U S 高亮 │ 列表 … │ 插入 …     │      │
│  （Mica      │      ╰───────────────────────────────────────╯      │
│   半透明）    │                                                │
│  260px       │              正文（最大宽 720px，居中）           │
│              │                                                │
│              │                                       1,234 字  │  ← 字数（右下角浮动小字）
└──────────────┴────────────────────────────────────────────────┘
```

| 区域 | 尺寸 | 材质/背景 | 说明 |
|------|------|-----------|------|
| 统一标题栏 | 高 52px，左右内边距 12px | Mica 半透明（退回 `--bg-window`） | **把系统标题栏和工具栏合为一体**（苹果的 unified toolbar）。左：侧栏开关、新建、打开（右键可选「打开文件夹…」）、保存；中：文件名 + 未保存圆点；右：「编辑 \| 阅读」滑块（§4.14）、源码、深浅色，再往右是 Windows 窗口按钮。空白处可拖动窗口 |
| 大纲侧栏 | 宽 260px，内边距 12px | Mica 半透明 | 与标题栏融为一体，**不画边框**；收起时正文向左展开，带 250ms 过渡 |
| 正文 | 自适应 | `--bg-content`（实色） | 左上角与侧栏交界处为 16px 圆角，形成「一张纸放在桌面上」的层次感；内容最大宽 **720px** 居中，左右内边距 56px，顶部 24px，底部留白 40vh |
| 格式栏 | 高 44px，胶囊形 | `--bg-elevated` + 浮层阴影 S | 悬浮在正文顶部居中，滚动时吸顶（距顶 12px）；窄窗口下自动换行为圆角矩形（圆角 22px） |
| 字数 | — | 无背景 | 正文右下角浮动，距边 16px，`--text-tertiary`，12px；**不再使用单独的状态栏** |

### 2.2 窗口

| 项目 | 值 |
|------|----|
| 默认尺寸 | 1180 × 820 |
| 最小尺寸 | 680 × 460 |
| 标题栏 | 隐藏系统标题栏，使用统一标题栏 + Windows 原生窗口按钮（titleBarOverlay），按钮区域颜色跟随主题 |
| 菜单栏 | 不显示；全部操作通过快捷键和界面按钮完成，菜单中的命令都有对应快捷键 |
| 窗口标题 | `● 文件名 — Paperwind`（● 仅在有未保存修改时出现，显示在任务栏；软件名 2026-11-06 由「Markdown 记事本」改为 Paperwind，见 PRD §7） |
| 启动 | 内容渲染完成后再显示窗口，避免白屏闪烁 |

## 3. 设计变量（Design Tokens）

### 3.1 颜色

颜色体系参照苹果系统色（System Colors）和语义色（Semantic Colors）：**中性灰阶 + 一个主色**。主色是备忘录的黄色，只用于：按下态、勾选、焦点、光标、引用竖线、列表符号。

**背景层级**（由下到上）

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| `--bg-window` | `#f5f5f7` | `#1c1c1e` | 窗口底（Mica 不可用时的标题栏、侧栏） |
| `--bg-content` | `#ffffff` | `#232325` | 正文「纸面」 |
| `--bg-elevated` | `rgba(255,255,255,.86)` + 背景模糊 20px | `rgba(44,44,46,.86)` + 背景模糊 20px | 格式栏、浮动菜单、弹窗等浮层 |
| `--fill` | `rgba(120,120,128,.12)` | `rgba(120,120,128,.24)` | 按钮悬停、输入框底、行内代码底 |
| `--fill-secondary` | `rgba(120,120,128,.08)` | `rgba(120,120,128,.16)` | 代码块底、表头底 |

**文字**

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| `--text` | `#1d1d1f` | `#f5f5f7` | 正文、主要文字 |
| `--text-secondary` | `rgba(60,60,67,.6)` | `rgba(235,235,245,.6)` | 图标默认色、引用、次要信息 |
| `--text-tertiary` | `rgba(60,60,67,.3)` | `rgba(235,235,245,.3)` | 占位提示、字数、已完成清单项 |

**分隔与主色**

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| `--separator` | `rgba(60,60,67,.12)` | `rgba(84,84,88,.6)` | 仅在必要处使用的细分隔线（表格线、分割线） |
| `--accent` | `#e6a700` | `#ffd60a` | 主色：光标、勾选、按下态图标、焦点 |
| `--accent-fill` | accent 18% | accent 22% | 按下态按钮底色、焦点光晕 |
| `--mark` | `rgba(255,204,0,.38)` | `rgba(255,214,10,.32)` | 高亮文字背景 |
| `--link` | `#007aff` | `#0a84ff` | 链接（苹果系统蓝） |
| `--danger` | `#ff3b30` | `#ff453a` | 删除类操作（如「删表」） |
| `--selection` | accent 28% | accent 30% | 文本选区 |
| `--seg-thumb` | `#ffffff` | `#48484a` | 分段控件的滑块（v1.3：深色下用纸面色看不清，单独定义） |

**对比度要求**：`--text` 对 `--bg-content` ≥ 7:1；`--text-secondary` ≥ 4.5:1；`--link` ≥ 4.5:1；按下态的 `--accent` 图标在 `--accent-fill` 上 ≥ 3:1。

**代码高亮配色**：采用 Xcode 默认主题的配色风格（浅色 Xcode Light、深色 Xcode Dark），通过 `--hl-*` 变量切换。

### 3.2 字体

| 用途 | 字体栈 |
|------|--------|
| 界面与正文 | `-apple-system, "SF Pro Text", "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", sans-serif` |
| 标题（≥20px） | `-apple-system, "SF Pro Display", "Segoe UI Variable Display", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", sans-serif` |
| 代码与源码模式 | `"SF Mono", "Cascadia Code", Consolas, "Microsoft YaHei UI", monospace` |

字体栈把苹果字体放在最前面，在苹果设备上自动使用原生字体，在 Windows 上使用等价字体。

### 3.3 字号（参照苹果 Dynamic Type 默认档）

| 层级 | 对应苹果样式 | 字号 | 字重 | 行高 | 段前 / 段后 |
|------|--------------|------|------|------|-------------|
| 标题 H1 | Title 1 | **28px** | 700 | 1.25 | 32px / 12px |
| 小标题 H2 | Title 2 | **22px** | 700 | 1.3 | 28px / 10px |
| 副标题 H3 | Title 3 | **20px** | 600 | 1.35 | 24px / 8px |
| H4 | Headline | 17px | 600 | 1.4 | 20px / 6px |
| H5 / H6 | Subheadline | 15px | 600（H6 用 `--text-secondary`） | 1.4 | 16px / 4px |
| **正文** | Body | **17px** | 400 | **1.6** | 段间距 10px |
| 代码块 | Callout（等宽） | 14px | 400 | 1.55 | — |
| 界面按钮/菜单 | Body（小） | 14px | 400 | — | — |
| 文件名、弹窗标题 | Headline | 15px | 600 | — | — |
| 侧栏条目 | Subheadline | 14px | 400（H1 条目 600） | 1.4 | — |
| 辅助文字（字数、标签、提示） | Footnote / Caption | 13px / 12px | 400 | — | — |

文档第一个元素不留段前间距。中文段落不首行缩进。

### 3.4 圆角、间距、阴影

**圆角刻度**（只能从中取值）

| Token | 值 | 用于 |
|-------|----|------|
| `--r-xs` | 6px | 行内代码、高亮、行内小元素、HTML 小标签 |
| `--r-sm` | 12px | 按钮（32px 高）、侧栏条目、下拉选项、小输入框 |
| `--r-md` | 16px | 输入框（36px 高）、代码块、图片、表格、提示条、正文纸面左上角 |
| `--r-lg` | 20px | 浮动菜单（非胶囊时）、下拉面板、上一篇 / 下一篇卡片 |
| `--r-xl` | 28px | 弹窗、拖拽提示框 |
| `--r-full` | 高度一半 | 格式栏、浮动菜单、提示气泡、主按钮、标签——**胶囊形** |

**同心规则示例**：下拉面板圆角 20px、内边距 8px → 内部选项圆角 12px；格式栏高 44px（胶囊 22px）、内边距 6px → 内部按钮 32px 高、胶囊形。

**间距刻度**：4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 px，只能从中取值（以 4 为基数）。

**阴影**（只用于浮层，柔和、大扩散、低不透明度）

| Token | 浅色 | 深色 | 用于 |
|-------|------|------|------|
| `--shadow-s` | `0 1px 2px rgba(0,0,0,.06), 0 4px 12px rgba(0,0,0,.08)` | `0 1px 2px rgba(0,0,0,.3), 0 4px 12px rgba(0,0,0,.35)` | 格式栏、浮动菜单 |
| `--shadow-l` | `0 2px 6px rgba(0,0,0,.06), 0 16px 48px rgba(0,0,0,.16)` | `0 2px 6px rgba(0,0,0,.3), 0 16px 48px rgba(0,0,0,.5)` | 弹窗 |

浮层外缘加一圈 0.5px 的 `--separator` 细线，让浮层在浅色背景上也有清晰轮廓（苹果浮层的常见做法）。

**线条**：不用于区域划分。只保留：表格线、分割线、浮层 0.5px 轮廓线、引用左侧 3px 圆头竖线（`--accent`）。

### 3.5 图标

- 造型参照 SF Symbols：**圆头圆角**的线条图标，24×24 画布，**描边 1.75px**，显示尺寸 18×18。
- 默认 `--text-secondary`；悬停 `--text`；按下态 `--accent`。
- 全部内联 SVG，不依赖图标字体或网络。
- 同一界面中所有图标视觉重量一致：新增图标必须同画布、同描边、同端点风格。
- 段落样式按钮使用苹果备忘录的 **「Aa」** 文字图标。

### 3.5b 应用图标（v1.6）

产品负责人经 8 轮比较后选定（2026-11-05）：**线条铅笔 + 残影 + 粒子飞散**，呼应链接跳转动效（§6.6b）里「字先抖动、再炸成粒子随风飘散」。

| 部分 | 规则 |
|------|------|
| 底板 | 圆角方块，100 画布上占 92×92、圆角 22；**暖阳橙**竖向渐变 `#FFC93C → #FF8A00`，上半部叠一层白色高光（不透明度 0.2 → 0） |
| 铅笔 | 白色**线条**勾出的铅笔（圆头圆角，与 §3.5 同风格），笔尖朝左下、倾斜 45°；笔芯为实心小三角；不用颜色区分木头和笔芯 |
| 抖动 | 主线条不透明度 0.85，上下各错开一层 0.25 的线条残影，表示笔在抖 |
| 飞散 | 笔身后半碎成圆角小方块，越往后越小、越稀、越淡，向右上飘走 |
| 小尺寸 | ≤ 32px 用精简版：去掉残影（会把笔身内部糊满），线条加粗到 5.5，粒子减为 3 排 |

- 母版与生成：`scripts/make-icon.cjs`（`npm run icon`）生成 `build/icon.svg`、`build/icon-small.svg`、`build/icons/*.png`、`build/icon.ico`（16–256 共 8 个尺寸）。改图标只改这个脚本，不手改生成的文件。
- 用于：安装包、exe、开始菜单 / 桌面快捷方式、任务栏、`.md` 文件关联的图标；开发运行时窗口用 `build/icon.png`。

### 3.6 动效

动效要**自然、快速、有物理感**（苹果的弹簧动画），只用于说明「东西从哪来、到哪去」，不做装饰。

| Token | 值 | 用于 |
|-------|----|------|
| `--ease` | `cubic-bezier(.25, .1, .25, 1)` | 颜色、背景变化 |
| `--spring` | `cubic-bezier(.34, 1.36, .64, 1)`（轻微回弹） | 浮层出现 |
| `--dur-fast` | 150ms | 按钮悬停、按下 |
| `--dur-base` | 250ms | 浮层出现/消失、侧栏收起、模式切换 |

| 场景 | 动效 |
|------|------|
| 按钮按下 | 底色变化 + 缩放到 0.96，松开回弹 |
| 浮动菜单、下拉面板、弹窗出现 | 从 0.96 缩放到 1 + 淡入，`--spring` |
| 侧栏收起/展开 | 宽度过渡，`--dur-base` |
| 提示气泡 | 自下向上 8px + 淡入，停留 1.6 秒 |
| 清单勾选 | 对勾缩放出现，`--spring` |
| 篇目间翻页（v1.4） | 旧页**粒子消散** + 新页**按方向滑入**，见 §6.6 |

`--glide`：`cubic-bezier(.32, .72, 0, 1)`（快速起步、长尾减速，无回弹），用于翻页时新页滑入（v1.4 新增）。

系统开启「减少动态效果」时，所有缩放和位移动效改为纯淡入淡出。

## 4. 组件规范

### 4.1 图标按钮

| 状态 | 底色 | 图标色 | 其他 |
|------|------|--------|------|
| 默认 | 透明 | `--text-secondary` | 32×32，圆角 `--r-sm`（格式栏内为胶囊） |
| 悬停 | `--fill` | `--text` | — |
| 按下（格式生效中） | `--accent-fill` | `--accent` | 光标处有该格式时保持 |
| 点击瞬间 | 同上 | — | 缩放 0.96 |
| 禁用 | 透明 | 30% 透明度 | — |

- 每个按钮有中文悬停提示：`名称  快捷键`，例：`高亮  Ctrl+Shift+H`。提示气泡为胶囊形、`--bg-elevated` 底、延迟 600ms 出现。
- 点击按钮**不能让编辑器失去选区和焦点**。

### 4.2 格式栏（胶囊）

组与组之间**用 8px 间距分隔，不用竖线**。从左到右固定顺序：

| 组 | 内容 |
|----|------|
| 1 段落样式 | **「Aa」** 按钮 → 弹出下拉面板：标题 / 小标题 / 副标题 / 正文 / 等宽（代码块），每项用对应字号预览（同苹果备忘录） |
| 2 文字样式 | 粗体、斜体、下划线、删除线、高亮 |
| 3 列表 | 清单、无序列表、有序列表 |
| 4 插入 | 引用、行内代码、代码块、表格、图片、链接、分割线 |

  - 只列含 Markdown 的文件夹（包括更深层里有 Markdown 的）；以 `.` 开头的隐藏文件夹、`node_modules`、`__pycache__`、`venv` 等工具文件夹和快捷方式链接一律跳过；最多 10 层、5000 篇。

### 4.13 上一篇 / 下一篇（v1.2 新增）

- 范围（v1.4）：只在**当前文章所在的同一个文件夹**内翻，不跨进子文件夹或上一级；翻页动效同理。
- 位置（v1.4 改）：**固定在窗口底部**，滚动时一直可见，宽度与内容区一致（720px，居中），离纸面底边 16px；不遮挡右侧滚动条。只有当前文件夹里有 2 篇及以上时才显示。
- 底衬：卡片后方是与纸面同色的底衬，上沿 24px 渐隐为透明（与格式栏的纸面底衬上下呼应）；底衬本身不接收点击，点在卡片以外的地方仍然作用于正文。
- 正文末尾的留白（40vh）保证最后一行可以滚到卡片上方；编辑时光标所在行不会被卡片挡住（自动滚动时为底部卡片留出空间）。字数统计移到卡片上方。
- 两张并排的卡片，各占一半，间距 12px：左「上一篇」、右「下一篇」（右侧卡片文字右对齐）。没有上一篇（或下一篇）时，该位置留空，另一张卡片保持原位不拉伸。
- 卡片：圆角 `--r-lg`（v1.4 由 `--r-md` 加大），内边距 12×16px，`--fill-secondary` 底，**无边框**；悬停 `--fill`；按下缩放 0.98（`--spring`）。
- 内容：第一行 12px `--text-tertiary`「‹ 上一篇」/「下一篇 ›」，第二行 15px `--text` 字重 600 篇名（单行省略）。
- 源码模式不显示；阅读模式、编辑模式都显示。卡片不属于文档内容，不会被保存。
- 作者可以为每一篇指定上一篇 / 下一篇，见 §4.13b（v1.5）。

### 4.13b 翻页索引（v1.5 新增，产品负责人要求）

作者可以为一篇文章**指定**「上一篇 / 下一篇」翻到哪一篇（可以跨文件夹），不再只按文件名顺序。指定的结果写在 Markdown 源文件里，换电脑、换软件都不会丢。

**在 Markdown 里的写法**：写在文档最开头的「属性区」（front matter，用两行 `---` 包起来），键名与文档站工具 VitePress 一致：

```markdown
---
prev: 第一卷/02-相遇.md
next: 番外/01-前传.md
---
```

| 写法 | 含义 |
|------|------|
| `next: 番外/01-前传.md` | 下一篇翻到这一篇。路径相对于当前文档，与文中链接写法相同，`/` 分隔，可跨文件夹 |
| `next: 附录.md#人物表` | 翻过去后滚到「人物表」标题 |
| `next: { text: 番外：前传, link: 番外/01-前传.md }`（或分两行缩进写 `text:`、`link:`） | 卡片上显示 `text` 而不是篇名 |
| `next: false` | 不显示「下一篇」 |
| 不写 `next` | 按文件名顺序（§4.13 原规则） |

`prev` 同理。属性区里其他内容（`title`、`tags` 等）程序不改动，保存时逐字保留。

**翻页卡片**（阅读、编辑模式都生效）：

- 卡片、`Ctrl+[` / `Ctrl+]` 按指定的目标跳转；卡片第二行显示目标的篇名（去掉编号，同 §4.11），写了 `text` 时显示 `text`。
- 有指定的一侧时，即使当前文件夹只有这一篇，也显示卡片。
- 目标文件不存在：卡片第二行显示「找不到 xx.md」（`--text-tertiary`），点击时提示「找不到“xx.md”」（与 §4b 一致），不跳转。
- 翻页动效（§6.6）照常播放，方向按卡片：去「下一篇」为向后、去「上一篇」为向前，跨文件夹也播放。

**编辑模式下直接在卡片上指定**（阅读模式下以下元素都不出现）：

- 打开了文件夹（篇目树中有 2 篇及以上）或已有指定时，编辑模式下卡片栏始终显示。
- 每张卡片靠内侧的上角（上一篇在右上、下一篇在左上，不挡文字）有一个「更改」小按钮：24px 圆形、铅笔图标、`--fill` 底，悬停卡片时出现（键盘聚焦时也出现）；点它不跳转，打开「指定上一篇 / 下一篇」弹窗。
- 空着的一侧显示**占位卡片**：透明底、1.5px `--separator` 虚线描边、圆角同卡片；第一行「‹ 上一篇」/「下一篇 ›」，第二行「＋ 指定…」（`--text-tertiary`）；设为不显示（`false`）的一侧第二行为「已隐藏 · 点击更改」。点击占位卡片打开同一个弹窗。
- 指定过的卡片，第一行后面加「· 已指定」（`--accent`），让作者分清是自己指定的还是默认顺序。
- **弹窗**（§4.7 样式，宽 480px）：标题「指定下一篇」；顶部搜索框（按篇名、路径过滤）；下面是**与侧栏篇目树相同的可折叠树**（v1.5 产品负责人选定，先做成按文件夹分组后又要求改为树）：顶部一行写树根文件夹名（文件夹图标 + 12px `--text-secondary` 字重 600）；文件夹行带折叠箭头和文件夹图标，**只有从根到本篇所在文件夹的那一串是展开的，其他文件夹都收起，单击文件夹行（或 `→` / `←`）展开、收起**；本篇所在的文件夹后面加「· 本篇所在」`--text-tertiary`；每深一层缩进 16px；文章行左边篇名、右边灰色的文件名，当前的目标打勾，当前这一篇显示「（本篇）」且不可选；列表最多显示约 8 行，可滚动；搜索按篇名、文件名、路径过滤，搜索时只显示匹配的文章和通向它们的文件夹（自动展开）；底部按钮：左「其他位置…」（系统文件选择框，只能选 Markdown 文件），右「恢复默认顺序」「不显示」「取消」。单击文章行即确定并关闭。`↑/↓` 选择、`Enter` 确定（在文件夹行上为展开 / 收起）、`Esc` 取消。
- 确定后：程序改写属性区中的那一行（没有属性区时在文档开头新建；删掉最后一个键时整个属性区一起删掉，文档恢复原样），卡片立即更新，文档变为「未保存」，`Ctrl+S` 后写入文件；可以 `Ctrl+Z` 撤销。

**双向对应**（v1.5，产品负责人选定）：上一篇 / 下一篇两边自动对应，来回翻一致。

- **保存时同步另一篇**：给「第二章」指定下一篇「番外」并保存后，程序同时把「番外」的上一篇写成「第二章」（指定上一篇时反过来同理）。只在保存时写另一篇：没保存、撤销掉的修改不会动另一篇。在源码模式里手改 `prev` / `next` 后保存，同样同步。
- **换掉或去掉**：「第二章」的下一篇从「番外」改成别的篇、恢复默认顺序或设为不显示并保存时，如果「番外」的上一篇正指向「第二章」，就删掉「番外」的这一项；新的目标照上一条写好。
- **有冲突先问**：「番外」的上一篇已经指定为别的篇（或设为不显示）时，指定的那一刻弹窗：「「番外」的上一篇已经指定为「第三章」。要改为「第二章」吗？」按钮「改为「第二章」」（主按钮）/「保留原来的」。选保留则只改「第二章」这一篇。在源码模式手改的，保存时再问。
- **另一篇正在别的窗口打开**：不直接写它的文件（避免两边互相覆盖），而是改那个窗口里的内容，那一篇变为「未保存」，并提示「「第二章」改了翻页顺序，这一篇的上一篇已同步，记得保存」。
- **只同步一层**：「番外」原来的上一篇（比如「第三章」）的下一篇不跟着改。
- 改另一篇的规则与本篇相同：只增删改属性区里的这一行、保持原来的换行方式、删空时整个属性区删除。目标文件不存在或不是 Markdown 时跳过。
- 保存提示改为「已保存 · 同步了「番外」的上一篇」（同步多篇时用顿号连接）。

**属性区在正文中的显示**：

- 编辑模式：正文最上方显示一行「属性」小标签（与 §5.1 包裹标签同样式：`--fill-secondary` 底、12px `--text-tertiary`，圆角 `--r-xs`），内容为「属性 · prev、next、title」（列出键名）；点击进入源码模式查看和修改。
- 阅读模式：不显示。源码模式：显示原文。
- 以前属性区会被当成「分隔线 + 大标题」显示，v1.5 起不再这样。

### 4.14 编辑 / 阅读滑块（v1.3 新增）

用一个**滑块式分段控件**显示并切换「编辑」和「阅读」两种模式，代替原来标题栏上的「阅读」图标按钮。

- **位置**：标题栏右侧，排在「源码」「深浅色」按钮之前，是标题栏中唯一带文字的控件。
- **外形**：胶囊形，高 28px，内边距 2px，`--fill` 底；两段各宽 48px，文字 13px。
- **滑块**：胶囊（`--seg-thumb` 底 + `--shadow-s`，同心：14 − 2 = 12 → 胶囊），停在当前模式下面，所在段文字为 `--text` 字重 600，另一段为 `--text-secondary`。
- **动效**：切换时滑块以 `--spring` 曲线平移（`--dur-base`），文字颜色同步过渡；减少动态效果时直接切换。
- **操作**：点击另一段即切换；也可以在滑块上左右拖动，松手时停到较近的一侧；`Ctrl+R` 同样切换；键盘焦点在滑块上时，←/→ 切换。
- **源码模式**：源码也是一种编辑，所以源码模式下滑块停在「编辑」一侧，「源码」按钮显示按下态；此时点「阅读」会退出源码模式、进入阅读模式。
- **悬停提示**：「切换编辑 / 阅读  Ctrl+R」。
- 与侧栏的「篇目 / 大纲」分段控件是**同一个组件**，外形和动效完全一致。

### 4.15 查找替换条（v0.2 新增）

- **位置**：浮在正文上方、靠右上角。编辑模式在格式栏下方（`top: 66px`），阅读模式贴顶（`top: 12px`）；右边缘距纸面 16px，最宽 `calc(100% - 32px)`。**绝对定位**，不参与流式布局，出现和收起都不移动正文、格式栏。
- **外形**：宽 360px，圆角 `--r-lg`，内边距 8px，`--bg-elevated` 底 + 背景模糊、`--shadow-s`、0.5px 轮廓线；出现时 `--spring` 缩放淡入，减少动态效果时直接出现。
- **第一行**：查找框（高 30px，圆角 `--r-sm`（同心：20 − 8 = 12），`--fill` 底，聚焦时 3px `--accent-fill` 光晕）+ 计数（13px，`--text-secondary`，显示「当前 / 总数」，没有结果时显示「无结果」）+ 上一处、下一处两个 28×28 图标按钮 + 「替换」文字次按钮 + 关闭图标按钮。

- **匹配高亮**：所有匹配底色 `--mark`；当前一处用 `--accent` 底、`#1d1d1f` 字（同主按钮的黄底黑字），在深色下同样清晰。
- **悬停提示**：上一处 `上一个  Shift+Enter`、下一处 `下一个  Enter`、替换 `替换  Ctrl+H`、关闭 `关闭  Esc`。
- **焦点**：打开后焦点在查找框；跳转、替换都不把焦点移走；`Esc` 关闭后焦点回到正文。

### 5.1 HTML 的显示（v1.4 改）

GitHub 风格的文档常用 HTML 排版（居中的标题区、折叠段落、HTML 表格）。原则：**看起来和 GitHub 上一样；文件里的 HTML 一个字都不改；任何脚本都不执行**。

| 类型 | 例子 | 编辑模式 | 阅读模式 |
|------|------|----------|----------|
| 完整的 HTML 块 | `<table>…</table>`、`<div align="right">…</div>`、`<p><img …></p>` | 直接渲染；悬停时右上角出现「HTML」小字，选中时 2px `--accent` 外框；内容在源码模式中修改 | 直接渲染 |
| 包裹的开始 / 结束标签 | `<div align="center">`、`</div>`、`</details>` | 收成一个 **单行小标签**：等宽 12px，`--fill-secondary` 底，`--text-tertiary` 字，圆角 `--r-xs`，不占整块 | 隐藏 |
| 折叠段落 | `<details>` + `<summary>…</summary>` … `</details>` | 显示为「› 摘要」一行，内容始终展开（方便编辑） | 显示为「› 摘要」一行，**默认折叠**，单击展开 / 收起，箭头旋转 90°（`--spring`）；`<details open>` 默认展开 |
| 对齐 | `<div align="center">` … `</div>` 之间的内容 | 按 `align` 居中 / 右对齐 | 同左 |
| 注释 | `<!-- … -->` | 单行小标签（同包裹标签） | 隐藏 |
| 行内 HTML | `<img src width>`、`<span>`、`<a name>` | 自成一体的（如 `<img>`）直接渲染；成对的开始 / 结束标签显示为小标签 | 自成一体的直接渲染；开始 / 结束标签隐藏 |

- **安全**：渲染前按白名单过滤（与 GitHub 的过滤规则同类）。只保留排版用的标签和属性（如 `div p span a img table tr th td details summary h1–h6 ul ol li br hr b i code pre sub sup kbd`，以及 `align href src alt title width height colspan rowspan`）；去掉 `<script>`、`<style>`、`<iframe>`、表单、`style` 和所有 `on…` 属性。链接只允许 `http(s)`、`mailto` 和相对路径，点击规则同 §4b。
- HTML 中的本地图片同样按文档所在文件夹解析。

### 5.2 流程图（Mermaid，v1.6）

试用时打开的工作文档里有 ```` ```mermaid ```` 流程图，原来只显示成代码。原则：**看起来像一张干净的图；文件里的代码一个字都不改；图里的任何脚本都不执行**。

| 状态 | 显示 |
|------|------|
| 阅读模式 | 只显示图，不显示代码。图放在与代码块相同的底板上（`--fill-secondary`、圆角 `--r-md`、内边距 16×20px），水平居中；比正文宽时先缩小，**最多缩到原大小的 80%**（保证字看得清），再宽就在底板里左右滚动 |
| 编辑模式，光标不在里面 | 同阅读模式，底板右上角显示「流程图」（12px，`--text-tertiary`，同代码块语言名）；悬停时鼠标为指针 |
| 编辑模式，单击图或光标移进来 | 图上方展开代码（与普通代码块相同），可直接修改；停止输入约 0.3 秒后图跟着更新，更新时不闪、不跳动（新图画好前保留旧图） |
| 光标移出 | 代码收起，只留图 |
| 代码写错 | 代码一直展开；图的位置显示「流程图有误：」加第一行错误说明（13px，`--text-secondary`）；不弹窗、不在控制台报错 |
| 源码模式 | 和普通代码块一样，只看到代码 |

- **配色**：跟随浅色 / 深色，颜色取自设计变量——节点底 `--bg-content`，节点边框与连线 `--text-tertiary` / `--text-secondary`，文字 `--text`，判断节点等强调处用 `--accent-fill` 底；字体与正文相同（系统字体），字号 14px。切换深浅色时图立即重画。
- **支持范围**：Mermaid 支持的图都显示（流程图、时序图、类图、状态图、甘特图、饼图等）。
- **安全**：安全级别为 strict——`click` 回调、图中的 HTML 标签、脚本都不生效，不加载任何外部资源。
- **离线与速度**：渲染组件随程序打包，不需要联网；只有文档里有流程图时才载入，没有流程图的文档打开速度不变。

### 6.6 翻页动效（v1.4 新增，产品负责人要求）

旧的一页**碎成粒子消散**，新的一页**按翻页方向滑入**。

- **何时播放**：同一文件夹的篇目之间跳转时——上一篇 / 下一篇卡片、`Ctrl+[` / `Ctrl+]`、点侧栏篇目。（v1.5：文中链接改用 §6.6b 的链接跳转动效。）方向按篇目顺序：往后翻（序号变大）为「向前」，往前翻相反。打开文件、打开文件夹、跨文件夹跳转、新建文档时**不播放**。例外（v1.5）：通过上一篇 / 下一篇卡片或 `Ctrl+[` / `Ctrl+]` 去往**指定的目标**（§4.13b）时，跨文件夹也播放，方向按卡片。
- **旧页**：正文区域原地定格，**文字和图片碎成约 3px 的细小粒子，保留原来的颜色**；纸面空白处不产生粒子。粒子从「离开的那一侧」开始逐列扫过（扫过全宽 220ms，另加 0–100ms 随机），每颗粒子朝离开方向飘出 40–140px、略微上扬，同时淡出，单颗寿命 380ms，约 700ms 内散尽。
- **新页**：**先散后进**——粒子开始后 450ms（旧页大部分已飘走）才出现，从翻页方向一侧 48px 处滑入，时长 560ms：位移用 `--glide`，淡入用慢起慢收曲线 `cubic-bezier(.45, 0, .55, 1)`（开头几乎看不见，最后才清晰）。整个翻页约 1 秒。（v1.4 调整：原为 120ms 后 32px / 420ms，产品负责人反馈新页进来太早、太突兀）；向后翻时新页从右侧进入、旧页粒子向左飘散，向前翻相反。新页滑入时已经在应到的位置（阅读记录、`#标题`）。
- **不动的部分**：标题栏、侧栏、格式栏、底部的上一篇 / 下一篇卡片、字数统计都不参与动效。
- **不打扰操作**：动效期间可以滚动、点击；连续快速翻页时，上一段动效立即结束，直接开始下一段，最终停在正确的篇目；结束后不留下任何覆盖层。
- **性能**：从操作到粒子开始 ≤ 100ms（不含「是否保存」对话框）；截图失败或太慢时，只播放滑入，不影响翻页本身。
- **减少动态效果**：系统开启时不产生粒子、不位移，新页 150ms 淡入。

### 6.6b 链接跳转动效（v1.5 新增，产品负责人要求）

点正文里的链接打开另一篇时（编辑模式 `Ctrl+单击`、阅读模式单击；**同文件夹、跨文件夹都播放**），播放与翻页不同的效果：**旧页的字先快速抖动，然后炸成粒子随风飘散；新的一页由风送来的细粒子「落」成——粒子落到哪里，哪里的字就清楚地显出来**。上一篇 / 下一篇、侧栏篇目仍用 §6.6 的翻页动效；同一篇里的 `#标题` 链接、大纲跳转仍是平滑滚动。

| 阶段 | 时间 | 效果 |
|------|------|------|
| 抖动 | 0–320ms | 正文定格（截图），按约 14px 的小格（大致一个字）各自随机抖动，幅度从 0 逐渐加到 3px |
| 炸开飘散 | 320ms 起（每颗另加 0–120ms 随机） | 文字碎成约 3px 的粒子，保留原色：先向四周迸开（初速 150–520px/s，很快减速），随后被「风」吹向右上方飘散，路径带一点上下起伏；800ms 内完全淡出 |
| 新页落成 | 650ms 起；风从左吹到右，左边的字先落（按横向位置延迟 0–320ms，另加 0–220ms 随机）；每颗 380–620ms | 新页每一处笔画都有一颗细粒子（柔和的小圆点，取文字颜色、半透明）**被风吹着飘来**：从落点上风处（左侧 18–68px、略偏下）顺风飘向落点，路上随风摆动（摆幅 5–13px，另有一阵阵的风让同一行一起摆），越靠近越平稳。**粒子落下的地方，那里的字就显出来**——显出来的是清晰的原样笔画（逐字按新页的字体、颜色、位置画出，与页面上的字逐像素对齐），不模糊、不成方块；落下的粒子越多，字越完整，所以文字是「被粒子一点点堆出来」的 |
| 补齐、换成真页 | 全部落定后 160ms 补齐没落到的笔画边缘；再 240ms 与真正的新页交叉淡换 | 两者几乎一模一样，看不出切换；图片、代码块底色、分隔线等在这时淡入。整个过程约 2.2 秒 |

- 新页已经在应到的位置（阅读记录、`#标题`）。（v1.5 多次按产品负责人反馈调整：旧粒子飞回聚拢 → 有大块色块；新页就地成形 → 末尾满屏马赛克；文字从模糊变清晰 → 粒子目的性太强、像是一下子清楚、且感觉不是粒子堆出来的。最终为：粒子随风飘来，落到哪里哪里的字就清晰地显出来。）
- 不动的部分、不打扰操作、截图失败时的处理与 §6.6 相同：截图失败只淡入；动效期间又点了别的链接或翻页，上一段立即结束；结束后不留下覆盖层。
- 性能：从点击到开始抖动 ≤ 100ms；旧页粒子上限与翻页相同（约 1.4 万），新页细粒子约 2 万以内（文字过多时自动加粗粒度）。
- 减少动态效果：不抖动、不产生粒子，新页 150ms 淡入。

### 6.6c 设置入口与动效选择（v1.7 新增）

**入口**：标题栏右侧、深浅色按钮之后的齿轮按钮（`data-cmd="settings"`）。点击打开「设置」弹窗（复用 §4.7 的样式），不是独立窗口。

**弹窗**：标题「设置」，按分组往下排；这一版只有「动效」一组，以后的新功能按分组追加。

| 元素 | 规则 |
|------|------|
| 分组标题 | 「动效」，下面一行小字说明「翻页和文中链接跳转时播放」 |
| 选项 | 单选列表，每行：名称 + 一句说明 + 右侧选中标记；点一下立即生效并保存 |
| 选项内容 | 经典（默认）、卷纸翻书、墨迹晕散、风吹纸页、轻盈淡入 |
| 底部 | 一行说明「系统开启「减少动态效果」时，统一只做淡入」+「完成」按钮；`Esc`、点遮罩同样关闭 |
| 宽度 | 与现有弹窗一致（`min(420px, 92vw)`），选项行高约 52px，触控和鼠标都好点 |

**偏好**：保存在 `localStorage` 的 `jumpEffect`，默认 `classic`；重启后保持。选择不写入用户的文档或文件夹。

**适用范围**：一套选择同时作用于篇目翻页（§6.6）与文中链接跳转（§6.6b）。链接跳转没有方向，按「往后翻」的编排播放。

| 特效 | 编排 | 约时长 |
|------|------|--------|
| 经典 | 翻页：粒子消散 + 滑入；链接：抖动 + 风中落字（即 §6.6 / §6.6b，行为不变） | 1.0s / 2.2s |
| 卷纸翻书 | 旧页从翻页方向的对侧被卷起揭开：折痕处只有一道很淡的暗边（约页宽 3%，最深约 8% 黑）和落在新页上的轻阴影，不抢正文；新页在被揭开的地方逐渐露出，像翻过一张纸。往后翻从右侧卷起，往前翻从左侧 | 0.8s |
| 墨迹晕散 | 旧页像墨滴落在纸上一样，从若干点化开、连成片消失；新页在下面逐渐露出。化开的顺序沿翻页方向扫过 | 0.85s |
| 风吹纸页 | 旧页裂成竖条，先离翻页方向近的一侧被风吹走，竖条边飘边淡出并带上下起伏；新页在下面露出 | 0.9s |
| 轻盈淡入 | 不截旧页、不产生覆盖层：新页 360ms 淡入并轻微上移（8px），像纸页轻轻浮现 | 0.36s |

**共同规则**
- 截图失败或太慢：只播放新页淡入，不影响跳转本身。
- 连点翻页 / 链接：上一段立即结束，直接开始下一段，结束后不留下任何覆盖层。
- 标题栏、侧栏、格式栏、上一篇 / 下一篇卡片、字数统计不参与动效。
- 性能：从操作到动效开始 ≤ 100ms（不含「是否保存」对话框）。
- 减少动态效果：无论选哪一种都不截图、不产生覆盖层，新页 150ms 淡入。
- 视觉：浅色、深色下都自然，不出现大块色块或马赛克；设置弹窗与标题栏按钮符合 §4.7 / §4.1。

## 7. 文案规范

- 全部使用**简体中文**，语气简洁、平实、友好，不用感叹号，不用「您」，不用技术术语（说「源码模式」，不说「Raw Markdown」）。
- 能短则短：按钮 2–4 个字，提示一句话说完。
- 按钮用**动词**：保存、恢复、丢弃、选择图片…
- 会打开系统对话框的操作，名称后加「…」：打开…、另存为…、选择图片…
- 统一术语：

| 统一用词 | 不用 |
|----------|------|
| 标题 / 小标题 / 副标题 / 正文 / 等宽 | H1 / H2 / H3、一级标题、Code |
| 清单 | 待办、Todo、任务列表 |
| 高亮 | 标记、荧光笔 |
| 代码块 / 行内代码 | 代码片段、内联代码 |
| 大纲 | 目录、TOC |
| 源码模式 / 阅读模式 | 源代码视图、预览模式 |
| 篇目（侧栏中同一文件夹的文章列表）/ 上一篇 / 下一篇 | 文件列表、文件树、章节、前一页 / 后一页 |

## 8. 可用性与无障碍

- 所有功能都能只用键盘完成；`Tab` 能在标题栏按钮间移动，焦点显示为 `--accent-fill` 3px 圆角光晕。
- 只靠颜色传达的状态必须有第二种提示（未保存：圆点 + 任务栏标题前的 ●）。
- 支持 `Ctrl+=/-` 缩放，在 80%–200% 下布局不错乱。
- 尊重系统设置：深色模式、减少动态效果、减少透明度（开启时所有半透明材质改为实色）。
- 可点击区域不小于 28×28px。
