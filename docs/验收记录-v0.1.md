## 4. 还要产品负责人做的事（做完即可发布）

测试文件在 `test-output/手动验收/`（甲.md、乙.md、丙.md）。

1. **AC-D02**：右键 `甲.md` →「打开方式」→「选择其他应用」→ 选 Paperwind 并勾「始终使用此应用」→ 关掉 Paperwind 后双击 `甲.md`，应直接用 Paperwind 打开。（以后想改回 Obsidian，同样操作选 Obsidian。）
2. **AC-D03**：① 关掉所有 Paperwind，从桌面图标打开（空白窗口），双击 `乙.md` → 在这个窗口打开；② 再双击 `丙.md` → 新开一个窗口；③ 再双击 `乙.md` → 不新开窗口，乙的窗口到最前。
3. （P1，可选）**AC-V08**：「设置 → 个性化 → 颜色」关掉「透明效果」，看标题栏和侧栏是纯色、字清楚；看完再打开。
4. 确认 v0.1 → 把版本号从 `0.1.0-beta.5` 改为 `0.1.0`、重新打包，打 `v0.1.0` 标签（先问）。

## 5. 已知问题（随 v0.1 发布，不影响门槛）

| 事项 | 影响 | 计划 |
|------|------|------|
| 1MB 级、含大量表格 / 代码块的文档里打字约 90ms/键 | 快速连打会有积压；600KB 以内无感 | 产品负责人决定暂不做「屏幕外不排版」，遇到再评估 |
| 链接跳转动效在大窗口、高分屏下掉帧 | 聚拢阶段偶有长帧 | 产品负责人决定先不处理 |
| 安装包约 117MB，没有代码签名 | 下载较大；安装时 Windows 提示「未知发布者」 | 签名需要证书，后续版本再定 |
| HTML 块在所见即所得模式下只读；`<details>` 只在顶层生效 | 编辑 HTML 要切源码模式 | 后续版本 |
| 改动过的块会被规范化（如 `*` 列表 → `-`） | 只影响改过的那一段，符合 AC-M04 | — |
| 窗口很窄时侧栏仍占 260px；没有「新建下一篇」、最近文件 | 功能范围 | 后续版本（PRD §8） |
| AC-E08（添加链接）在 M3 的 5 轮完整自测里失败过 1 次，原因未查明 | 之后各轮都通过；自测已加现场记录 | 再出现时按记录查 |
| 从 beta.2 升级时，beta.2 自带的卸载程序会整键删除 `Markdown`（可能是 Obsidian 的关联） | 只影响装过 beta.2 又装了 Obsidian 的试用者 | 发 beta.5 给试用者时提醒：`.md` 双击异常就在「打开方式」里重选一次 |
